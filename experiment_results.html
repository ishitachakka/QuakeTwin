EXP 1

Post-Disaster Packet Loss — Decision Accuracy

Four realistic disaster scenarios defined by V2X packet loss rate. QRL+QKD consistently outperforms the PPO baseline, with the gap widening sharply as network conditions degrade. At disaster-level (40% loss), QRL+QKD retains 82.7% accuracy versus PPO's 67.5% — a 15.2 percentage point gap.

Key result: Under sensor corruption equivalent to disaster-level packet loss without QKD protection, QRL accuracy drops from 100% to 61.2%. QKD integration holds this to 82.7%, a 21.5pp recovery attributable solely to authenticated channel integrity.

SEC 2

Hybrid Quantum-Classical Security Architecture

A dual-mode security design ensures resilience regardless of quantum infrastructure availability. QKD is preferred when a quantum channel is active; post-quantum cryptography provides a standards-compliant fallback when it is not.

MODE A — QKD ACTIVE

When a quantum optical channel is available between sensor nodes and the QuakeTwin backend, BB84 QKD provides information-theoretically secure key exchange. QBER is monitored continuously; values above 11% trigger immediate re-keying and alert the QRL agent to distrust the affected channel.

Experimental results confirm QRL+QKD maintains near-perfect decision accuracy up to 20% MITM attack rate under this mode — a regime where unprotected PPO has already degraded to ~88%.

MODE B — POST-QUANTUM FALLBACK

When QKD links are unavailable (infrastructure damage, range limitations), the system falls back to NIST PQC lattice-based cryptography (CRYSTALS-Kyber for key encapsulation, CRYSTALS-Dilithium for signatures). This satisfies NIST SP 800-208 and maintains computational security against quantum adversaries.

Mode transitions are automatic: the QKD health monitor detects link failure and negotiates a PQC session within one heartbeat interval, ensuring continuity of authenticated V2X data delivery to the QRL agent.
